# UI 重设计行为契约

这些契约描述的是现有数据安全、任务连续性和能力边界。新 UI 若要改变其中任何一项，必须在迁移矩阵中记录变更理由和批准结果。

## C-01：卡片最低可保存条件

- 现状：题目文字和图片至少存在一项；完全空白不能保存。
- 验收：分别验证“仅文字”“仅图片”可以保存，“无文字且无图片”显示错误且不创建记录。
- 关联功能：`CARD-004`、`IMAGE-001`。
- 当前来源：`src/domain/card.ts`、`src/domain/card.test.ts`。

## C-02：卡片状态由内容计算

- 现状：缺少题目或知识点时为“待完善”；有用户作答时还需要错因位置/原因之一和错误类型；无用户作答时需要正确解法，满足条件后为“已整理”。
- 验收：保存不同完整度的卡片，检查列表和详情状态一致。
- 关联功能：`CARD-003`、`CARD-004`。
- 当前来源：`src/domain/card.ts`、`src/domain/card.test.ts`。

## C-03：编辑已有卡片必须防止静默覆盖

- 现状：更新携带 `expectedRevision`；实际 revision 不一致时拒绝保存。
- 验收：打开同一卡片的两个编辑上下文，先保存 A，再保存 B；B 必须得到冲突反馈，不能覆盖 A。
- 关联功能：`CARD-008`。
- 当前来源：卡片服务测试及 Tauri IPC 契约测试。

## C-04：草稿与正式保存严格区分

- 现状：编辑器每 700ms 将草稿写入 localStorage；草稿不等于卡片已保存。已有卡片 revision 变化后，不恢复旧 revision 的草稿。
- 验收：输入后不保存并离开，再次进入可恢复；外部更新卡片后旧草稿不覆盖新版本；正式保存后草稿被清除。
- 关联功能：`CARD-006`、`CARD-007`、`CARD-008`。
- 当前来源：`src/features/cards/CardEditorPage.tsx`。

## C-05：AI 整理建议不得自动写入

- 现状：编辑器 AI 建议先逐字段审阅；只有用户接受的字段进入表单，之后仍需点击“保存卡片”才持久化。
- 验收：生成建议后直接离开，卡片保持原值；接受部分字段但不保存，持久化卡片仍保持原值；接受并保存后只有所选字段变化。
- 关联功能：`AIORG-003`、`AIORG-004`。
- 当前来源：`src/domain/ai.test.ts`、`AiReviewPanel.tsx`、`CardEditorPage.tsx`。

## C-06：AI 建议必须暴露不确定性和编辑冲突

- 现状：不确定字段默认不应被选择；建议生成期间用户改过的字段显示冲突提示。
- 验收：构造不确定建议和并发编辑，确认默认勾选与冲突标识正确，且用户仍可自主选择。
- 关联功能：`AIORG-003`。
- 当前来源：`src/domain/ai.test.ts`、`AiReviewPanel.tsx`。

## C-07：图片导入先编辑后入库

- 现状：卡片编辑器选择或拖入合法图片后先进入旋转/裁剪弹窗；确认后才调用资产导入。
- 验收：选择图片后取消，卡片和资产列表均不增加；确认后出现预览；导入失败有错误反馈。
- 关联功能：`IMAGE-001`、`IMAGE-002`、`IMAGE-003`。
- 当前来源：`useImageImport.ts`、`ImageEditorDialog.tsx`。

## C-08：知识卡片必须有来源证据

- 现状：一个具体知识点对应一张由来源错题派生的知识卡片；显示来源数量、错误样本和覆盖度，并可回到来源错题。
- 验收：修改来源卡片后重新进入知识卡片，派生摘要和来源 revision 关系正确；无来源时不能伪造知识卡片。
- 关联功能：`KNOW-001`、`KNOW-002`、`KNOW-003`、`KNOW-004`。
- 当前来源：`learningContent.ts`、`KnowledgeCardView.tsx`。

## C-09：AI 知识卡片的有效性绑定来源 revision

- 现状：AI 生成结果仅在来源数量相同且每张来源卡片 revision 一致时继续显示；当前结果不持久化，刷新页面会丢失。
- 验收：生成后修改任一来源卡片，再返回知识卡片；旧 AI 内容必须失效。刷新后不得假装已经持久化。
- 关联功能：`KNOW-004`。
- 当前来源：`KnowledgeCardView.tsx`、`KnowledgeContextView.tsx`。

## C-10：复习题按选定知识点和错题生成并保存为习题卡

- 目标：用户先选择一个或多个知识点，再从这些知识点的关联错题中勾选生成依据；可继续缩小到任意错题组合。
- 数量约束：生成总数不得小于所选错题数，分配时每道所选错题至少生成 1 张练习题。
- 保存约束：每道成功生成的新题均保存为独立习题卡片，并记录知识点、来源错题及来源 revision，不能只作为当前页面的临时题组存在。
- 验收：检查知识点多选、来源错题全选/取消、数量下限联动、生成进度、保存卡片数，以及每道来源错题至少被一张卡片覆盖。
- 关联功能：`REVIEW-001`、`REVIEW-002`、`REVIEW-003`。
- 当前来源：`KnowledgeContextView.test.tsx`、`learningContent.ts`。

## C-11：Agent 只读自动，写入必须审批

- 现状：搜索、读取可自动执行；创建、修改、删除必须显示工具、影响范围并等待批准。拒绝后不修改数据。
- 验收：分别发起搜索、创建、修改和删除；搜索无需批准，后三者在批准前数据不变，拒绝后仍不变。
- 关联功能：`AGENT-003`、`AGENT-008`、`AGENT-009`。
- 当前来源：`AgentControls.tsx`、`AgentTimeline.tsx`、Agent 运行时与 reducer 测试。

## C-12：Agent 新对话只能由标题栏操作触发

- 现状：聊天文本中的“创建新对话”等命令不会重置会话；标题栏按钮才会重置。当前实现会先取消活动 run，并拒绝所有待审批操作。
- 验收：发送“创建新对话”，历史仍保留且出现边界提示；点击标题栏新对话后只剩欢迎消息；待审批写操作没有执行。
- 关联功能：`AGENT-011`。
- 当前来源：`useAgentHarness.ts`、`AgentWorkspace.tsx`。

## C-13：Agent 运行必须可观察、可停止

- 现状：状态、决策摘要、工具开始/完成、等待批准、完成、取消和步骤上限都具有时间线状态；活动 run 可停止。
- 验收：运行工具任务时能观察顺序状态；停止后显示取消，不再接受该 run 的迟到错误为新失败消息。
- 关联功能：`AGENT-007`、`AGENT-010`。
- 当前来源：`agentReducer.ts`、`useAgentHarness.ts`。

## C-14：浏览器预览不得冒充桌面真实能力

- 现状：浏览器显示“本地模拟运行”提示，使用 localStorage 和模拟 Agent；真实 AI、工具、凭据与本地文件只在 Tauri 桌面运行时执行。
- 验收：浏览器必须持续显示预览提示；桌面版不得显示模拟标识；验收报告分开记录两种运行时结果。
- 关联功能：`AGENT-013`、`DATA-001`、`DATA-002`。
- 当前来源：`AgentWorkspace.tsx`、`browserAgentService.ts`、`agentService.ts`。

## C-15：用户和 AI 内容不得执行原始 HTML

- 现状：内容支持 Markdown 和 LaTeX，但跳过并清理原始 HTML。
- 验收：普通公式正确渲染；输入 HTML 或脚本标签时不得创建可执行 DOM。
- 关联功能：`CONTENT-001`。
- 当前来源：`MathContent.tsx`、`MathContent.test.tsx`。

## C-16：敏感凭据不得在 UI 回显或跨边界复用

- 现状：API Key 保存到系统凭据库，已保存密钥不回显；Codex 使用知拾专用登录目录，不读取或复用本机 Codex 凭据。
- 验收：保存后重新进入页面，Key 字段仍为空；留空保存保留原 Key；退出 Codex 只影响知拾专用登录。
- 关联功能：`AICONN-002`、`AICONN-003`、`AICONN-004`。
- 当前来源：`AiConnectionsPage.tsx`；必须桌面验收。
