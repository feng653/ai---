# 学习流程升级原型

> 日期：2026-09-05｜状态：已按图片收录、知识树找题、错因问答定位重设计，待人工走查与 C06 评审

入口：[index.html](./index.html)。这是完全独立的原生 HTML/CSS/JavaScript 示例，不依赖项目包、开发服务或正式数据库。可在支持本地 HTML 的浏览器中手动打开。原型默认沿用浅色、绿色学习空间，重点评审操作顺序与页面职责。

## 1. 已落实的产品决定

| 决定 | 原型呈现 |
|---|---|
| C01：错题学习闭环优先 | 错题收集、回看、来源选择、生成练习及来源回看 |
| C02：S1～S3 本轮，S4 后置 | 错题库与错因复习为主；已有知识卡放在次级折叠入口，保留查看与编辑 |
| C03：业务页直接操作，Agent 完整编辑所有卡片并联网搜索 | 原页整理错题、原页生成练习；Agent 引用三类卡片、字段与图片修改预览、批准保存；联网来源呈现示例 |
| C04：先应用，再保存错题 | 整理结果逐字段选择；应用后明确提示尚未保存，再点击保存 |
| C05：练习生成并保存 | 来源、数量、入库说明在一页；取消独立计划批准页，模拟完成后新增练习卡 |

需求与决定依据：[升级计划书](../../项目升级从需求到落地计划书.md)。核查依据：[执行记录](../../项目升级执行记录.md)。

## 2. 建议的查看顺序

1. **添加错题**：首先添加图片，也可填写题目，直接保存；也可点击 AI 整理，等待模拟结果，选择建议并应用，修改后再保存。
2. **回看与练习**：在错题库搜索并打开卡片，再返回；从卡片选择练习来源，设置问答数量后点击“生成并保存”。完成后主动打开练习库、查看答案及来源。
3. **Agent 编辑**：从任意卡片点击“让 Agent 编辑”，发送“请完善这张卡片”。展开修改预览中的“调整建议内容”，可改该类卡片的全部展示字段、添加/移除/前移图片，再批准保存或拒绝。分别用错题、知识卡和练习卡走一次。
4. **Agent 搜索呈现**：输入“联网查找导数资料”，查看模拟回答及来源位置。原型不实际搜索，来源是带标识的预置链接。
5. **失败与恢复**：运行中可停止，或切到其他页面，通过“最近进度”返回。刷新时未完成模拟任务标为已中断。原型故障注入控件默认隐藏，不属于正常产品界面；对应失败分支仍保留。

原型还支持“把解法改成：……”和“把补充说明改成：……”这样的有限文本演示，其余自然语言不具备真实模型理解能力。改动预览可直接调整字段，用来评审编辑能力的入口和保存过程。

## 3. 原型边界

- AI 整理使用预置建议，新问答从来源错题的错因、错误位置、笔记和解法字段提问（每来源最多四种）；未验证用户输入对应的诊断质量、题型或难度适配，不能用它评估 AI 效果。
- 联网搜索仅展示入口、失败和来源样式；没有网络检索实现。点击示例链接会由用户浏览器打开外部网页，该链接不代表本轮检索证据。
- 本地模拟数据使用单独的 `zhishi-learning-flow-upgrade-v1` 浏览器存储键，不读写正式应用的数据。大图片可能超出浏览器配额，保存失败会提示。
- 图片只演示选择、预览、移除和前移，最多 3 张、单张不超过 15MB；裁剪、旋转、真实图片理解及资产生命周期不在本原型实现范围。此临时上限不替代正式 PRD 的 Provider 校验。
- 三类卡片字段共用原型编辑结构；ID、版本和来源审计信息由原型维护。练习知识点限制为已有名称，错题主要知识点最多 3 个。
- 手工编辑与 Agent 使用同一示例卡片数组；有版本冲突时阻止旧内容覆盖。手工编辑的复杂冲突合并恢复尚未制作，当前保留草稿并提示回详情核对。Agent 可重新读取最新版本并保留拟修改的字段。
- 新建、编辑、整理、练习生成覆盖本轮主路径；删除、多卡批量编辑、知识卡重生成与回滚、完整知识树、真实 AI 接入设置、数学 Markdown 排版等沿用正式需求，未在本原型完整展示，不表示删除或已经验收。
- 练习里的思路输入仅用于本次练习查看，不新增评分或正式作答记录系统。

## 6. 本轮重设计补充

产品定义与重大待决策项以[错题整理与错因复习方案](../../错题整理与错因复习-重设计方案.md)为准。

- 图片位于编辑表单首部；长答案和解法折叠，但原内容完整保留。
- 侧栏保留学科 / 章节 / 知识点层级；每级可筛选，缺失分类进入待归类节点，支持多知识点。列表文字检索与分类筛选同时生效。
- `@` → 学科 → 章节 → 知识点 → 卡片；↑↓ 选择，Tab 或 Enter 补全，Shift+Tab 返回，Esc 关闭。支持中文输入法及多个明确卡片引用，逐张批准编辑。不再使用“本次引用的卡片”下拉框。
- 新生成只接受明确选中的错题，使用源字段形成回忆和规则解释问答；未整理错因的来源提示先补充，不生成无依据的答案。参考内容本身不代表经过正确性验证。
- 默认初始示例使用概念问答。已有浏览器数据及旧练习继续保留，不重置存储；历史缺失章节在两类已知示例上补齐，其余进入待归章节。
- `taxonomy.js`、`mentions.js`、`recall.js` 均为本目录独立原生脚本，无生产代码或包依赖。

补充待走查：图片先于文字；同名异章筛选；未分类材料可找到；@ 四级选择与返回、IME、鼠标与多引用；答案折叠与来源返回；旧练习兼容。浏览器访问仍受策略限制，这些交互尚未取得实测通过记录。


## 7. 错因复习翻面卡片

- 列表直接显示题目正面；点击卡片翻到答案背面，再点一次返回题目。详情页使用相同交互。
- Enter / 空格同样可翻面；隐藏的一面不参与辅助阅读。系统开启减少动态效果时取消翻转动画。
- 切换页面后重新从正面开始；翻面只改变当前查看状态，不写入卡片内容。后台页面重绘保留当前面的状态。
- 原题来源与编辑入口位于翻面区外；可选的个人回答仍保留在详情页折叠区。
- 本轮只做独立脚本语法、资源与差异检查；点击、键盘、长答案、窄屏和翻面效果仍待浏览器实际走查。


## 8. 界面文案精简（用户明确要求）

删除页面英文装饰标题、流程引导、副标题、品牌口号、Agent 欢迎与功能说明、输入示例、翻面操作提示和原型说明横幅。文档负责记录操作方式和模拟限制。故障注入控件从正常界面隐藏。

界面只保留页面名称、题目与答案、分类与来源、表单标签和操作、计数及当前状态；模拟运行仅保留顶部“模拟”标记。保留未保存、失败、冲突等必要信息和非可视辅助标签。用户保存的题目、答案、笔记和历史对话不删除；旧版自动问答的固定原型说明仅在翻面卡展示时省略，不改写原始数据。

本轮已完成脚本语法、资源路径、格式和差异检查；浏览器视觉与交互仍未实测。


## 9. 添加与继续编辑共用入口

有未保存的错题草稿时，侧栏及错题库页头的“添加错题”原位替换为“继续编辑”，进入同一草稿；取消单独草稿提示栏。所有错题草稿保存后恢复“添加错题”。知识卡和复习问答的编辑草稿不影响此入口。已有多个未保存错题时依次恢复，不删除其他草稿。
