# 错题整理与错因复习原型

入口：[index.html](./index.html)。原生 HTML/CSS/JavaScript，无项目模块依赖。

当前功能：图片优先收录、建议应用后明确保存、待归档与学科/章节/知识点树、@ 多层引用、错因问答翻面卡、长答案收起与全页详情、AI 接入设置、侧栏收缩。知识卡模块已移除。

所有 AI、图片理解、供应商连接和搜索均为模拟；API Key 只在页面会话内存中。此原型不能证明桌面真实功能或模型正确性。

长答案在卡片中限制高度，翻到背面后点击“查看详情”显示完整内容。全页背景虚化，关闭或 Escape 返回原卡背面。

验收依据：[重设计方案](../../错题整理与错因复习-重设计方案.md)、[移除及展开清单](../../知识卡移除与复习卡展开实施清单.md)。静态原型仅检查语法和资源路径，视觉效果待人工走查。
