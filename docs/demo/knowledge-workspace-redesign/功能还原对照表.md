# 知拾工作台重设计 Demo 功能还原对照表

## Demo 边界

- 设计依据：`docs/ui-redesign/feature-inventory.md`、`behavior-contracts.md`、`journey-matrix.md`、`migration-matrix.md` 与 `docs/截图/temp/1.png`～`4.png`。
- 本 Demo 只实现 UI、键盘入口与动画状态，不连接 Tauri、AI、凭据库或真实卡片存储；任何保存、删除、登录、审批和生成结果均为视觉模拟。
- 视觉原则：冷静的纸白/墨绿知识工作台；按钮图标使用粗实心或双色 SVG，并在按钮内几何居中；不使用小三角、细线箭头、Emoji 或无意义状态文案。
- 品牌原则：Codex、DeepSeek 使用项目现有官方 PNG；项目标志采用折页方案，不再提供图标选择按钮。侧栏收起后只保留居中的折页图标，不显示“大字知”。
- 动效原则：页面切换 180–260ms、面板 220–320ms、卡片空间变形 360–480ms；支持 `prefers-reduced-motion`，快速重复操作必须落到正确终态。
