## 用户特别要求核对

| 要求 | 结果 |
|---|---|
| 使用原有供应商官方标志 | `codex.png`、`deepseek.png` 与 `public/brands/` 对应文件哈希一致 |
| 继承模型选择等关键设置 | Codex、DeepSeek、自定义 API 均保留模型选项；API 表单保留 Base URL、Key、测试和保存 |
| 不使用小三角/细线形符号 | 代码与渲染文本不使用 `›`、`⌄`、`▼`、`▾`、`▶`；树展开改用实心加/减方块 |
| 收起态不用“大字知” | 已选用折页图标作为唯一项目标志，并删除“图标方案”按钮 |
| 按钮图标居中 | 收起态品牌、导航和收起按钮统一为 48×48，图标使用 `place-items:center` 且文字不占网格位置 |
| AI 接入页去掉无用大介绍 | 页面只保留标题、服务列表和字段级帮助文字 |
| 删除错题库宣传标题 | 已删除 `LEARNING INDEX` 与“把每一次错误，变成可追溯的知识。”，搜索、数量与页签直接上移 |
| 复习题按实际需求重构 | 先多选知识点，再任选范围内错题；生成数量使用数字输入框和右侧加减按钮，下限等于来源错题数；结果全部显示为已保存习题卡片 |
| 编辑页可选已有知识树 | 学科、章节、知识点三列联动，可将选中节点加入归档，也可手动新建 |
| 包含 Agent 小窗 | 已实现完整小窗、控制项、时间线、审批和手动新对话 |
| 不出现“本地空间/数据已保存”类文案 | 仅保留持续可见的“交互演示”运行时边界标识 |
| 卡片点开动画与打开后设计 | 已实现共享位置变形、详情双栏信息架构和反向关闭 |
