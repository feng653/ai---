## 4. 当前三类生成路径

### 4.1 创建页整理错题

起点：创建页已有有效图片。

1. 点击“AI 整理这道错题”，页面暂存并派发。
2. 正常产品语义应等待 AI 结果；该 demo 使用 Agent 内“生成审核提案”按钮模拟完成，需要先打开“在 Agent 中查看”。这段属于演示控制路径。
3. 从结果入口打开字段审核，或回创建页点击“审核整理结果”。
4. 调整采用的字段，点击“应用已采用的 N 项”。
5. 返回创建页的编辑草稿，仍显示尚未正式保存。
6. 点击保存，demo 更新保存状态。

需保留：只应用被采纳字段、冲突保护、图片和草稿关联、明确正式保存结果。

简化准备：原页展示进度与审核入口，把模拟完成控件移出普通路径。C04 已确认保留分步保存；原型必须表现“建议已应用、尚未保存”以及保存失败后仍能继续编辑。

### 4.2 生成知识卡

起点：普通页面，Agent 关闭且无活动任务；已有可用来源错题。

1. 打开 Agent，选择“生成或完善知识卡”。
2. 点击“选择来源”，进入主内容区；核对或调整来源，点击“确认来源”返回 Agent。
3. 核对目标知识点和要求，点击“创建任务”。
4. demo 通过“生成知识卡草稿”模拟完成分析。
5. 点击结果入口，进入主区审核知识草稿。
6. 审核并保存，或放弃草稿。

需保留：明确来源、待审核状态、来源变化保护，以及上一正式版本。

已定分工：普通任务无需打开 Agent；Agent 同时具备知识卡完整编辑能力。知识卡生成与整体组织深度改造后置，已有能力保留。

### 4.3 生成练习

起点：普通页面，Agent 关闭且无活动任务；已有可用来源卡片。

1. 打开 Agent，选择“生成练习”。
2. 点击“选择来源”，进入主内容区；核对或调整来源，点击“确认来源”返回 Agent。
3. 设置数量、难度、补充要求。
4. 点击“创建任务并查看计划”。
5. 在新显示的计划中点击“批准计划”，开始运行。
6. demo 用“完成并保存整批”模拟成功，或用其他演示按钮模拟错误与修复。
7. 点击“打开练习批次”，返回主区。

需保留：来源范围、数量和参数约束、明确写入授权、结果校验、保存失败反馈和来源回看。

已确认的简化：来源与参数页同时说明入库行为，点击“生成并保存”后直接运行并保存合格结果。取消独立计划批准页，不增加生成后审核页；生成或保存失败需明确反馈并保留输入。
