# 错题整理与错因复习：重设计方案

> 2026-09-05｜依据用户本轮明确的产品定位更新｜独立原型已补齐，用户已授权开始正式实现。
>
> 本文的定位与流程取代升级计划中的泛化知识沉淀、泛化 AI 出题表述；C03 全卡编辑与联网能力、C04 应用后另存、C05 生成并保存继续有效。历史数据不删除。

## 1. 产品只围绕两个价值组织

**快速收好一道真实错题，过一段时间还能按知识点找到它；把这次错误变成可主动回忆的问答，减少重犯。**

不是要求用户再维护一套笔记库。知识点在本轮承担分类与检索职责，错题是证据，问答是复习方式。是否有效要观察之后能否独立识别并纠正同类错误，不能用生成题数或 AI 自评分替代。

主流程：**添加图片 → 整理为草稿 → 应用建议 → 保存错题 → 按学科 / 章节 / 知识点找到原题 → 生成错因问答并保存 → 先回答、后对照 → 回原题检查。**

## 2. 页面及操作

| 区域 | 用户任务 | 本轮设计 |
|---|---|---|
| 添加错题 | 尽快留下材料 | 图片入口在表单最前。题目文字可为空；有图即可先保存。分类未完成时进入待归档，不阻断收集 |
| 整理编辑 | 从图片变成清楚的卡片 | 同页 AI 整理；正式能力需识别题目、提出分类、记录第一处错误和原因。先显示建议，应用到草稿，再明确保存。答案与长解法折叠 |
| 知识树 | 找到特定知识点的错题 | 学科 → 章节 → 知识点，逐级展开并筛选。按实际路径匹配；同名知识点在不同章节不混合。支持未归类内容 |
| 错题详情 | 理解当时怎么错的 | 原题图片、题干、错误位置与原因、答案与解法；可继续编辑、选择为复习来源 |
| 错因复习 | 主动回忆并纠错 | 明确选择来源错题，生成与错误相关的短问答；以翻面卡片展示：默认正面问题，点击显示背面答案，再次点击回题目；来源入口独立保留，旧练习可回看 |
| Agent | 自然语言跨卡任务 | 保留错题卡和练习卡的字段、图片编辑和联网搜索能力；日常收集、整理、查询、复习可直接完成 |
| 知识卡 | 已决定移除 | 清除知识卡实现，保留错题分类知识点 |

Agent 输入 `@` 弹出紧凑候选：学科 → 章节 → 知识点 → 具体卡片。上下键移动，Tab 或 Enter 进入下一级，Shift+Tab 返回，Esc 关闭。选择卡片后将引用插入文字，可继续输入另一个 `@`。只有最终选中的卡片被引用，选择分类不代表授权编辑整个分类。多卡编辑逐张展示、批准或拒绝。

## 3. 复习问答如何区别于泛化出题

以“求定义域只检查根式，漏掉分母不为零”为例：

| 问答目的 | 问题示例 | 应对照的要点 |
|---|---|---|
| 概念条件 | 根式与分式同时存在时，定义域需要同时满足哪些条件？ | 被开方数非负、分母非零，取交集 |
| 错误识别 | 为什么只写 x ≥ 2 还不够？ | 未排除使分母为零的 x = 3 |
| 防错方法 | 下次写出定义域前，检查哪两项？ | 对照原式逐项检查，再取交集 |
| 返回原题 | 遮住答案重新解释原题，之前遗漏的条件补上了吗？ | 自己独立作答，再核对正确结果 |

正式生成应具备：一问一个具体要点、明确来源卡片和版本、参考回答与依据对应、不超出来源所能支持的结论。缺少错因时提示回原题整理，不能凭空替用户编造错误原因。只有原题图片时可先收录，不能假装已经完成理解。

**本轮独立 demo 的模拟范围**：用已保存的错误原因、错误位置、检查笔记和正确解法形成最多四种提问；不识别图片，不理解补充要求，不验证答案正确性。新建内容与来源逐条关联；用户手动核对来源记录也可能发现原记录本身有错。

生成并保存仍沿用 C05，但“合格”必须区分结构合格与内容正确。生产版不能把确定性的结构检查称为正确性验证。内容明显缺失、来源不一致的结果不得入库；质量验收用人工标注样本，不增加 AI 自判正确的环节。

检索练习研究支持主动提取而非只重复阅读，并在特定实验中观察到迁移收益；这不能直接证明本产品能提高考试成绩，更不能证明 AI 生成题就是真题。[Butler，2010，研究摘要](https://pubmed.ncbi.nlm.nih.gov/20804289/)。间隔提取研究支持隔一段时间再回忆，但不能据此替用户确定统一复习间隔。[Karpicke 与 Bauernschmidt，2011，研究摘要](https://pubmed.ncbi.nlm.nih.gov/21574747/)。因此本轮先做好有来源的问答，自动间隔调度暂不加入主流程。

## 5. 从原型到正式落地

1. **当前：原型修改及边界记录。** 用图片添加、未归类卡、同名异章知识点、来源缺失和键盘引用等情境走查；确认 C06 及上述重大取舍。
2. **冻结行为与验收口径。** 更新现有 PRD，明确卡片字段、路径分类、来源版本、失败保留、概念问答质量。测量现版收录用时和知识点找题成功率，再确认 C07 目标；不虚构基线。
3. **S1 收录与找题。** 生产版图片到草稿流程、部分建议应用、明确保存、未归类收容、完整知识树筛选；沿用资产和版本保护。优先让真实材料可被找到。
4. **S2 Agent 引用。** 接入实际分类数据与键盘补全，保持全字段和图片编辑、来源范围、批准写入、冲突保护及真实联网能力。
5. **S3 错因问答。** 使用明确选择的错题及版本，按错误点生成短问答、带依据入库；正面问题、背面答案，点击翻面，返回来源。对来源不支持、答非所问、泄露答案的生成结果做质量检查。
6. **验收与交付。** 生产变更执行 AGENTS.md 对应验证；实际桌面验证图片、AI、持久化、重启和错误恢复，再按 C08 决定交付。正式程序唯一产物仍遵循仓库规则。

不在本轮默认范围：笔记系统重建、自动间隔算法、知识掌握评分、题库采购或抓取、考试押题、批量旧卡迁移。
